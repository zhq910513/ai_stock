# 代码与文档标准

## 优先级

1. 正确与可追溯。
2. 可读、可维护。
3. 最小实现。
4. 性能只在已证明瓶颈时优化。

## 规则

- 迁入保持现有服务合同，不静默改公共接口。
- 无证据不抽象，不预造兼容层。
- Python 注释与文档字符串用 reST：`:param:`、`:return:`、`:raises:`。
- 封装方法说明做什么、为什么、关键参数；调用前写清业务意图。
- 遵守 flake8；浅调用，避免过度封装。
- 缺真实数据保留 `NULL` / 缺口码。

## 文档

- 工作区治理只写在 `docs/` 与根目录 `AGENTS.md`。
- 每个落点目录只有一份 `README.md` 契约。
- 服务迁入后，运行事实以该落点 README + 源码为准。
