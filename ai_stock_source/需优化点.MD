# 需优化点

本文件只记录非阻断优化账本，不作为已落地事实源。已落地事实以当前代码、运行容器、SQLAlchemy metadata、`infra/sql/bootstrap_schema.sql` 和各模块根目录唯一 README 为准。

## P1 SQLAlchemy metadata 渲染入口补齐

- 现状：根目录 `AGENTS.md` 要求代码与运行事实以 SQLAlchemy metadata 和 `infra/sql/bootstrap_schema.sql` 为准，但 2026-06-17 只读搜索未发现当前仓库存在真实 SQLAlchemy `MetaData` / declarative metadata 定义；`packages/db-schema` 当前实际通过 `psycopg` 顺序执行 `infra/sql/*.sql`，Alembic baseline 也委托执行同一批 SQL 文件。`infra/sql/bootstrap_schema.sql` 仍是当前运行基线渲染文件和审计事实。
- 影响：不阻断当前 Docker build、schema-bootstrap、SQL 合同测试或 source 底座索引上线；但后续若继续新增表/索引，仍需人工同步分段 SQL、bootstrap_schema 和 README，存在 drift 风险。
- 后续建议：单独设计并补齐 SQLAlchemy metadata 渲染链路，或明确把当前项目 schema 事实源收敛为 SQL 文件序列 + bootstrap_schema + Alembic 委托入口。完成前，每次 schema/index 改动都必须同步 `infra/sql/*.sql`、`infra/sql/bootstrap_schema.sql`、相关 README / DATA_ASSETS 和 SQL 合同测试。
